# CortaViral AI

Aplicativo web para analisar vídeos por URL, encontrar trechos com potencial de retenção e exportar cortes verticais com legendas automáticas.

## Stack
- FastAPI
- yt-dlp
- Faster-Whisper
- FFmpeg
- Interface responsiva HTML/CSS/JavaScript

## Status
MVP em desenvolvimento. A pontuação é heurística e não garante viralização.

Consulte a documentação de instalação e uso após a inclusão dos arquivos do projeto.
